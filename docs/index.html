NVIDIA DLSS for Kingdom Come: Deliverance, the first game. A cleaner image than the built-in anti-aliasing, and more FPS by rendering below your screen resolution.

Download Config guide & cvar database Source on GitHub

Install

  1. Download kcd-clarity-<version>.zip from the latest release.
  2. Copy dinput8.dll and nvngx_dlss.dll into the game's Bin\Win64 folder (Steam: right-click the game > Manage > Browse local files).
  3. In the game's Options > Video, set Anti-aliasing to SMAA 2TX.
  4. Press F8 in game, choose DLSS and a quality level.

Uninstall: delete the two files. Other mods that use a dinput8.dll (ASI loader, other DLSS mods) can't be installed at the same time.

Requirements

  • NVIDIA RTX graphics card (RTX 20 series or newer), recent driver. AMD and Intel cards: FSR or XeSS through OptiScaler.
  • Windows, or Linux with Steam's Proton.
  • Kingdom Come: Deliverance, Steam version 1.9.8. Other versions are untested; the mod warns you if it doesn't recognise the game.
Early version. DLAA (100%) is the most reliable mode. Below 100% some effects can still look wrong. Please report what you see, with a screenshot and kcd_clarity.log.

AMD & Intel GPUs

OptiScaler can run FSR or XeSS in place of DLSS.

  1. Install the mod as above.
  2. Copy OptiScaler.dll into Bin\Win64 renamed to winmm.dll (or version.dll), plus OptiScaler.ini. Not dinput8.dll: that's this mod.
  3. In game, choose DLSS in F8, then press Insert for OptiScaler's menu and pick the upscaler.

Untested so far. Reports welcome.

Linux (Proton)

Install the files as on Windows, then set the game's Steam launch options:

  • NVIDIA: WINEDLLOVERRIDES="dinput8=n,b" PROTON_ENABLE_NVAPI=1 %command%
  • AMD / Intel, with OptiScaler as winmm.dll: WINEDLLOVERRIDES="dinput8,winmm=n,b" %command%

Without the override Wine uses its own dinput8.dll and the mod doesn't load. Untested so far. Reports welcome.

Config guide

Most user.cfg tweaks shared online are refused, overwritten by the video options, or do nothing. The config guide builds a config that works, checks any config line by line, and lists all 4007 console variables with what each one really does.
