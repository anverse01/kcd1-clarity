How the game loads configs

Order

  1. system.cfg, then user.cfg (game folder), while the engine starts.
  2. A few thread/worker settings are read once, right after that.
  3. Your saved profile is applied: resolution, V-Sync, FPS cap, FOV, the distance sliders, and every quality option. Each quality option is a preset group that sets dozens of cvars (209 in total).
  4. autoexec.cfg runs when the game starts. (That this is after step 3 is likely but unverified.)
  5. Changing a video option later re-applies its whole group.

Parsing rules

  • A comment must start the line, with ; or --. A comment after a value is part of the value (harmless after a number, not after text).
  • user.cfg needs name = value. Lines without = (like #comments or bind) are ignored. autoexec.cfg also accepts name value and commands like bind.
  • Whole-number cvars cut off fractions: r_HDRBloom = 0.4 becomes 0, which turns bloom off.
  • An empty value (name =) sets 0.
  • The file must be called exactly user.cfg; user.cfg.txt is never loaded.
